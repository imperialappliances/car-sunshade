# Car Windshield Sun Shade Umbrella landing page

Static page: index.html, css/styles.css, js/main.js, assets/. No build step.

- Publish: upload the folder to a GitHub repo, then Settings > Pages > Deploy from branch `main`, folder `/ (root)`.
- Prices: the three `.tier` cards in index.html (the summary copies them).
- Colours and fonts: the `:root` block at the top of css/styles.css.
- Order email / form service: the `action` on `<form id="order">`.
- How-to-use video: assets/video/how-it-works.mp4, then uncomment `<source>` and set each step's `data-start`.
- Pixels: paste the Meta and TikTok base codes where marked in `<head>`.
